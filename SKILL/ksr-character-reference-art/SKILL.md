# KSR 角色四宫格 · CDTV 适配

参考用户提供的 KSR角色四宫格提示词书写。本技能只替换角色板，不改剧本、场景、道具或已生成媒体。

默认输出一张 2×2 四宫格，同一角色、同一服装、同一体型：左上 FACE FRONT 正面脸部特写，右上 FACE SIDE 侧面脸部特写，左下 BODY FRONT (NO FACE) 正面完整全身（保留完整头部轮廓，不刻画五官），右下 BACK 背面完整全身。全身格从头顶至鞋底完整入画。身份细节由两张脸部特写承担，不增画第五格、侧身全身格、音色标签或声纹条。

纯色冷灰 #606570 棚拍背景，单一侧后方约 45° 主光；保持脸部辨识度、肤色、服装和道具本色。保留项目真人/2D/3D 等画风，不强迫所有项目转成写实或统一染蓝。仅四个固定英文面板标签；角色标题仅在用户明确提供标题原文时添加。图号、工作流说明和音色描述不画入图。

从既有资产描述保留年龄、发型、脸部特征、服装形制和差异标记。没有原文依据，不添加武器、饰物或新身份。用户自行编写构图或关闭默认构图时，按其选择执行，避免追加互相矛盾的布局。

角色板是身份与造型参考，不能宣称能锁定视频全段。严格第一人称的手部/袖口参考和镜头起始图需单独制作，不能把四宫格当作 POV 第 0 秒。

既有角色描述含“全程不露脸”等视频约束时，保留原资料，在本次角色板请求中明确其不约束上排正/侧脸特写；不借此改写任何视频提示词。若用户要的本来就是无脸手部资产，应关闭默认角色板构图，按手部说明出图。

## 实际接入

唯一默认布局数据为 [assets/role-layout.json](assets/role-layout.json)。前端角色生图模块在构建时导入该资源，覆盖普通生图及有参考图片的编辑生图；界面展示模板版本与最终提交预览。修改此文件后须重新构建并同步程序，单独改安装目录文档不会热更新已打包的前端。

只在发起后续生成时组装新模板。既有资产 ID、角色描述、图片、视频、台词及手工构图保持，不进行数据库迁移或自动重生成。发布前用隔离请求检查实际提交的 prompt 和参考图，真实出图仍须另行验收。
