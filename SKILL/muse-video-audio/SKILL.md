# CDTV：Muse 视频声音规则

适用对象是 CDTV 中 modelName=muse-video 的 API 模型。此文件是 Muse 专用补充，不把 Muse 当成 Seedance。

参考规则来源：漫剧老李 V7.4.26 的 model-adapters.md §5.2、sd-qc-engine/references/sound-design-template.md、sd-feed-engine 的台词完整性契约：
https://github.com/lixiaoxiao9888-create/manju-laoli-skill

1. 固定声线只含性别、年龄、音高、稳定声音质地。喘息、发颤、哭腔、低语属于逐句表演，不写成全角色恒定属性。同一声线在一个镜头内只写一次。
2. 画面、对白、画外音和音效分开写。台词原文用引号；无对白明确写“对白：无。”。有 OS/VO 时另起“画外音：角色（OS/VO）：‘原文’”，实际使用双引号。
3. 台词确认后成为本镜基准。输出前逐句、逐序、逐说话人检查，新增、遗漏、重复、串镜、改写均阻止提交。用户主动编辑台词后需点击“确认当前台词”更新基准。
4. Muse 当前只传图片与文字，不宣称支持 reference_audio、voice ID 锁音色。声音文字设定不等于真实音频；真实音频文件不等于已合入成片。只在合成成功且结果文件仍对应时显示“已合入成片”。
5. 不自动给无对白镜头生成喘息，也不追加上一镜台词。不把 Seedance/H3 的字符、时长或参考数量限制复制到 Muse。
6. Muse 视频生成完成后自动在本地提取音轨，用 Whisper small 做文字识别，与提交时冻结的台词基准比较。视频、音频不上传识别服务。CPU 工作排队，原片不改写。
7. 检查结果分为：文字一致待试听、文字不一致需复核、未核验。缺组件、失败、超时、未明确台词都不能显示通过。机器识别会误识，禁止据此声称音色、自然度、说话人身份或口型合格。
8. 旧视频可手动点击“核验视频台词”；原视频不会自动重生成或扣费。更新提示词只影响后续生成，已生成视频需重生成或另配音才能改变声音。

本地识别组件：whisper.cpp（MIT），ggml-small-q5_1；模型和程序来源见 THIRD_PARTY_AUDIO.txt。所有子进程隐藏控制台窗口。
