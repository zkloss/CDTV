# CDTV - AI 漫剧与短剧自动化创作客户端

[English](README.en.md) | 简体中文

一个使用 Vue 3、pywebview、Python 和 Playwright 构建的本地桌面应用，面向 AI 漫剧与短剧制作全流程自动化。将项目管理、素材整理、视听导演分镜编排、视频生成与任务调度整合到统一工作区，减少重复配置与提交工作。**项目数据与素材保存在本机，无需部署后端、无需 Java、客户端免注册登录；图片、视频、音频与文本生成统一在设置中心配置自定义模型 API。**

## ✨ CDTV 2.0 核心特性升级

- 🎬 **内置 V7.4.20 导演引擎**：
  - 采用 **1 位总导演 + 12 位专业副导演**（文学编剧、角色设定、场景设计、视听分镜、提示词工程等）模块化矩阵分工协作。
  - 内置 **48 套完整影视工业级规则库**，覆盖景别构图、机位运动、情绪张力、光影氛围与连贯性控制。
- 📋 **M1 Wirelist 工业级线表编排**：
  - 严谨的资产-分镜线表映射机制，保证 **1:1 分镜完全提取**，杜绝大模型在分镜创作时的偷懒、合并或省略镜头。
- ⚡ **Seedance 2.5 / 2.0 双代视听智能适配**：
  - 面向通用 API 中转站与直连网关，无缝封装兼容 Seedance 2.5 与 Seedance 2.0 专属提示词生成规范。
  - 引入 **D-lock 深度锁定尾帧技术** 与多机位平滑转场支持，大幅提升镜头间角色与场景一致性。
- 🧰 **AI 影视工具箱**：
  - 音频生成、字幕生成与压制、视频去水印、60fps 补帧、参考视频逆向拆解五个辅助引擎集成在同一工作台。
- 🎞️ **双创作模式**：
  - **墨柴工坊**面向火柴人与极简科普视频，预设风格模板一键直出，长时长自动进入全片无缝组装。
  - **短剧创作**面向多集连续剧，资产、分镜轨道与首尾帧继承在同一时间线内完成整集连拍与缝合导出。
- 🧩 **全格式剧本文档导入 + AI 重构**：
  - 支持 Markdown、TXT、Word（docx / doc）、PDF、Excel（xlsx / xls）、CSV、JSON 单文件导入，支持整季文件夹批量导入与文本粘贴导入，自动识别剧本、小说章节与松散分镜表并适配为结构化创作数据。
  - 检测到小说或粗文本（分镜少、无台词字段）时，可调用文本模型按工业级分镜格式自动重构为可投产剧本，输出镜头号、时长、场景、画面、台词、景别运镜、环境音、转场与拍摄约束。
- 🔓 **纯净开源默认 + 工作流快捷接入**：
  - 首次启动不预置任何模型或第三方中转站，模型列表完全为空。
  - 模型管理内置常用平台工作流模板：AutoDL ComfyUI（内置 27 款 H3 系列视频工作流）、RunningHub、LiblibAI 哩布、ComfyUI 原生（8188）与自定义接口，一键填入 API 地址并自动拉取远端模型列表。
- 📺 **全新品牌与视觉体验**：
  - 全新升级 TV 专属桌面应用图标与视觉品牌形象。
  - 深度优化本地任务并发隔离与工作区状态保持。

## 功能概览

- **项目管理**：项目与章节管理，Markdown 剧本编辑，实时保存与标题锚点导航。
- **剧本文档导入**：支持 .md / .txt / .docx / .doc / .pdf / .xlsx / .xls / .csv / .json 单文件、整季文件夹批量与文本粘贴导入；检测到小说或粗文本时可调用 AI 文本模型重构为工业级分镜剧本。
- **模型管理与工作流接入**：文本 / 图片 / 视频 / 音频四类模型配置，内置 AutoDL ComfyUI、RunningHub、LiblibAI、ComfyUI 原生与自定义工作流模板，一键填入并从 API 自动拉取远端模型列表。
- **素材与资产库**：提示词、人物 / 场景 / 道具 / 白模 / 音频素材的分类管理、本地预览与跨分镜复用。
- **AI 导演与分镜编排**：内置导演引擎与影视规则库，支持分镜线表编排、景别与机位设定、情绪与光影控制，以及首尾帧继承和镜头衔接校验。
- **视频批量生成**：本地选图、提示词、画面比例与时长设置，任务进度与结果回传；统一通过设置中心配置的模型 API 生成。
- **短剧创作（多集连续剧）**：集数与分镜轨道管理，上一镜尾帧自动作为下一镜首帧引导，支持整集连续预览与一键缝合导出正片。
- **墨柴工坊（火柴人 / 极简科普）**：内置科学解说、极简火柴人打斗、沙雕日常、生活小剧场等风格预设，支持 9:16 / 16:9 / 1:1 画幅与 5 / 10 / 15 / 30 / 50 秒时长，长时长自动进入全片无缝组装模式。
- **AI 影视工具箱**：音频生成、字幕生成（可压制进画面）、视频去水印、60fps 补帧、参考视频逆向拆解五个辅助引擎。
- **抽卡历史与导出**：同一条分镜保留多个生成版本，可在播放器下方直接切换回放，并导出完整成片 MP4。

## 快速上手

1. **启动客户端**：已有打包版本时运行 `CDTV.exe`；源码运行按 [开发指南](docs/DEVELOPMENT.md) 安装依赖并启动。
   Mac 已加入适配代码，按步骤操作见 [Mac 用户安装说明](docs/MAC_SETUP.md)，开发与构建细节见 [macOS 运行与打包](docs/DEVELOPMENT.md#macos-运行与打包)。
2. **建立项目**：创建项目和章节，编辑 Markdown 剧本，添加本地素材。
3. **准备分镜**：建立视频创作任务，逐条填写分镜，或通过创作数据 JSON 一键导入。
4. **配置模型 API**：首次启动模型列表为空（纯净开源默认，不预置任何第三方中转站）。在设置中心 → 模型管理中添加文本 / 图片 / 视频 / 音频模型，填写 API 地址后可自动拉取远端模型列表，也可使用「⚡ 工作流快捷接入」一键导入。
5. **生成与预览**：为分镜选择图片、填写视频描述和支持的参数，提交后查看任务进度与生成结果。

客户端本身免登录；生成功能使用设置中心里已启用的模型 API，本地项目编辑与素材管理无需配置模型。

## 本地存储与 AI 能力边界

项目数据与上传文件默认保存在本机：

- **内置本地存储服务**：`local_storage.py` 使用标准库 `sqlite3` + `http.server`，启动时在 `127.0.0.1:18081` 提供数据与文件存储接口。
- **单机账号**：应用内使用本地用户，无需注册或登录。

默认数据库为 `data/storage/storage.db`（SQLite），上传文件位于 `data/storage/files/`。设置中心可修改存储目录；生成视频默认写入 `output/`。备份时先关闭客户端，再复制整个实际存储目录。

> 当前实现：`/ai/image` 支持 OpenAI 兼容的图片生成和参考图编辑；`/ai/audio` 支持 MiniMax 音色设计及试听音频；`/ai/video` 支持 Seedance 任务提交、查询和成片保存；`/ai/chat` 支持 Chat Completions 与完整 `/messages` 地址的非流式文本转发。接口读取设置中心已启用模型的 API 地址、API Key 和模型名，生成的媒体保存到本地。图片地址可填写服务根地址、带 `/v1` 的地址或完整 `/images/generations` 地址；音频和视频建议按下表示例填写完整接口地址。

## 模型配置示例

在设置中心的“模型管理”里可保存**文本 / 图片 / 视频 / 音频**模型配置。四类模型的表单字段一致，区别在“类型”和“模型名”。首次启动时模型库为空白（纯净开源默认，不含任何预置中转站），下表为手动配置时的参考示例。

下表为常用的中转与直连配置示例，**表中不包含任何 API Key**——Key 请填写你在对应服务商或自定义中转站获取的密钥。

### 视频工作流快捷接入

「模型管理」内置以下工作流模板，点击即可填入 API 地址与模型名；填入 API Key 后点【获取模型列表】可拉取该平台的全部可用工作流：

| 平台 | 预设 API 地址 | 说明 |
| ---- | ------------- | ---- |
| AutoDL ComfyUI | `https://www.autodl.art/api/v1/comfyui/comfyui_workflow/minimax_h3_zm_u24` | 内置 27 款 H3 系列工作流（多图多音频、15 秒、动作迁移、Wan2.2 等） |
| RunningHub | `https://www.runninghub.cn/task/openapi/create` | 填入 RunningHub 令牌后使用 |
| LiblibAI 哩布 | `https://api.liblib.art/api/v1/generate/comfyui` | 哩布在线 ComfyUI 工作流 |
| ComfyUI 原生 | `http://127.0.0.1:8188` | 本地或自建 ComfyUI 服务 |

## AI 创作数据与 JSON 导入

项目内置 `SKILL/` 目录，包含导演引擎库与规则文档（`SKILL.md` + `references/` 数据模型与规则文档），作为把剧本转换成结构化、可校验的漫剧分镜数据的工业标准。

创作数据可通过 JSON 导入项目，用来验证导入流程与字段结构。
