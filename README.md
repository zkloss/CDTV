# CDTV - AI 漫剧与短剧自动化创作客户端

[English](README.en.md) | 简体中文

一个使用 Vue 3、pywebview、Python 和 Playwright 构建的本地桌面应用，面向 AI 漫剧与短剧制作全流程自动化。将项目管理、素材整理、视听导演分镜编排、视频生成与多账号调度整合到统一工作区，通过浏览器自动化减少重复配置与提交工作。**项目数据与素材保存在本机，无需部署后端、无需 Java、客户端免注册登录；Doubao 视频生成需单独登录对应账号。**

## 功能概览

- **项目管理**：项目与章节管理，Markdown 剧本编辑，实时保存与标题锚点导航。
- **素材与资产库**：提示词、人物 / 场景 / 道具 / 白模 / 音频素材的分类管理与本地预览。
- **视频批量生成**：本地选图、提示词、画面比例与时长设置，任务进度与结果回传；支持浏览器自动化及 API 生成通路。
- **多账号管理**：每个生成账号拥有独立的浏览器 Profile 与登录态；账号列表保存在本机。
- **额度与调度**：对合法持有的账号记录每日视频额度，运行中加锁，任务结束自动释放，避免重复提交；不用于绕过平台额度或风控。
- **链接转换与视频处理**：保留分享链接转换、视频下载与去水印处理功能。使用前应核实素材授权、平台许可及内容标识要求。

## 快速上手

1. **启动客户端**：已有打包版本时运行 `CDTV.exe`；源码运行按 [开发指南](docs/DEVELOPMENT.md) 安装依赖并启动。
   Mac 已加入适配代码，按步骤操作见 [Mac 用户安装说明](docs/MAC_SETUP.md)，开发与构建细节见 [macOS 运行与打包](docs/DEVELOPMENT.md#macos-运行与打包)。
2. **建立项目**：创建项目和章节，编辑 Markdown 剧本，添加本地素材。
3. **准备分镜**：建立视频创作任务，逐条填写分镜，或通过创作数据 JSON 一键导入。
4. **配置生成账号**：在设置中心添加账号，打开该账号的浏览器并手动登录。Windows 网页自动化需要应用目录下的 `runtime/chrome-win64/chrome.exe`；Mac 查找 Mac 版内置浏览器或本机 Google Chrome。
5. **生成与预览**：为分镜选择图片、填写视频描述和支持的参数，提交后查看任务进度与生成结果。

客户端本身免登录，网页自动化生成需要单独登录对应服务账号。只做本地项目编辑和素材管理时，不需要配置模型 API。

## 本地存储与 AI 能力边界

项目数据与上传文件默认保存在本机：

- **内置本地存储服务**：`local_storage.py` 使用标准库 `sqlite3` + `http.server`，启动时在 `127.0.0.1:18081` 提供数据与文件存储接口。
- **单机账号**：应用内使用本地用户，无需注册或登录。

默认数据库为 `data/storage/storage.db`（SQLite），上传文件位于 `data/storage/files/`。设置中心可修改存储目录；生成视频默认写入 `output/`。备份时先关闭客户端，再复制整个实际存储目录。

> 当前实现：`/ai/image` 支持 OpenAI 兼容的图片生成和参考图编辑；`/ai/audio` 支持 MiniMax 音色设计及试听音频；`/ai/video` 支持 Seedance 任务提交、查询和成片保存；`/ai/chat` 支持 Chat Completions 与完整 `/messages` 地址的非流式文本转发。接口读取设置中心已启用模型的 API 地址、API Key 和模型名，生成的媒体保存到本地。图片地址可填写服务根地址、带 `/v1` 的地址或完整 `/images/generations` 地址；音频和视频建议按下表示例填写完整接口地址。

## 多账号管理

这里的“多账号”指每个视频生成账号拥有独立浏览器 Profile 与独立每日生成额度，客户端分别记录其额度并调度任务：

1. 点击右上角“添加账号”，输入便于识别的名称。
2. 选中账号，点击“打开浏览器并登录此账号”，在弹出的浏览器中手动登录后关闭窗口。
3. 重复以上步骤添加更多账号。

每个账号的登录状态独立保存在 `data/accounts/<账号ID>/profile`，浏览器 Profile 文件保存在本机。客户端为每个账号维护本地每日视频额度，生成成功后自动扣减，次日重新计数；生成中账号会进入“运行中”锁定，任务结束自动释放。
